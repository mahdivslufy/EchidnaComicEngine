---

## 💎 پیشرفت‌های اساسی نسخه Pro (Key Advancements)

1. **کلین ۱۰۰٪ سفید بالون بدون لکه‌های خاکستری (Pure Solid Interior Fill):**
   * به جای استفاده از الگوریتم‌های تارساز (مثل Telea) در داخل بالون‌های سفید، موتور پس از ایزوله‌سازی جوهر فونت با فیلترهای مورفولوژیک، آن را با رنگ سفید خالص (`#FFFFFF`) جایگزین می‌کند. نتیجه: بالون کاملاً وکتوری و بدون هرگونه افکت شطرنجی یا شبح کلمات قبلی.
2. **مرکزسنجی ریاضی با پیوند مورفولوژیک حروف (Morphological Letter-Bridging Centroid):**
   * حروف سیاه داخل بالون دیگر باعث چندتکه‌شدن کادر نمی‌شوند. الگوریتم با اعمال `MORPH_CLOSE` توده سفید یکپارچه بالون را استخراج کرده و مرکز ثقل دقیق ممان‌ها ($M_{10}/M_{00}, M_{01}/M_{00}$) را پیدا می‌کند.
3. **تایپ‌ستینگ لوزی و بیضوی متقارن (Diamond/Oval Silhouette Wrapping):**
   * بالون‌های کمیک بیضی هستند، نه مستطیل! سیستم با اعمال محدودیت پهنای ۷۶٪ روی خط اول و آخر، فرم لوزی/بیضی متقارن ایجاد کرده و از برخورد متن با انحنای بالون جلوگیری می‌کند.
4. **پاک‌سازی و تایپ‌ستینگ داینامیک متون خارج بالون (Artwork SFX & Text Inpainting):**
   * افکت‌های صوتی (SFX) روی تصویر با ماسک دایلیشن وسیع پاک شده و ترجمه فارسی آن‌ها به صورت پویا با فونت سنگین، اوت‌لاین مشکی ضخیم (۳ تا ۴ پیکسل) و رنگ‌های اکشن کمیک (قرمز، زرد) در زاویه مناسب آرت‌وورک جای‌گذاری می‌شود.
5. **سیستم بازیابی خودکار خطا در پردازش دسته‌ای (Auto-Retry Resilience):**
   * در صورت اختلال در پاسخ یک صفحه، موتور به صورت خودکار با پرامپت و مدل پشتیبان امتحان مجدد می‌کند و هیچ صفحه‌ای رها نمی‌شود.

## 🚀 نحوه اجرا (CLI Usage)

```bash
# ترجمه یک فایل کامل CBZ کمیک
python main.py --cbz "comic.cbz" --out-cbz "comic_persian.cbz"

# ترجمه تک‌صفحه
python main.py --image "page.jpg" --out "page_translated.jpg"
```
